## REQ-001: 画像コンポーネント - アップロード機能

### 要件

**When** ユーザーが画像コンポーネントを追加する
**Then** 以下の2つの方法で画像を設定できる:

1. **既存画像アップロード**
   - ローカルファイルからのドラッグ&ドロップ
   - ファイル選択ダイアログからの選択
   - 対応形式: JPEG, PNG, GIF, WebP
   - 最大サイズ: 10MB
   - アップロード先: Supabase Storage → CDN配信

2. **外部URL指定**
   - 直接URLを入力
   - プレビュー即時反映

### 受け入れ条件

- [ ] アップロードボタンをクリックするとファイル選択ダイアログが開く
- [ ] ドラッグ&ドロップでファイルをアップロードできる
- [ ] アップロード中はプログレスバーが表示される
- [ ] アップロード完了後、キャンバスに画像が即時反映される
- [ ] 対応外形式の場合はエラーメッセージを表示
- [ ] 10MBを超えるファイルの場合はエラーメッセージを表示

## REQ-002: 画像コンポーネント - AI画像生成（NanoBanana Pro）

### 要件

**When** ユーザーがAI画像生成タブを選択する
**Then** NanoBanana Pro APIを使用して画像を生成できる

### 機能

1. **プロンプト入力**
   - テキストエリアでプロンプト入力
   - 日本語対応
   - プロンプトテンプレート提供

2. **生成オプション**
   - アスペクト比: 1:1, 16:9, 9:16, 4:3, 3:4
   - スタイル: 写実的, イラスト, アニメ風, ビジネス

3. **生成フロー**
   - 「生成」ボタンクリック
   - ローディング表示（1-2秒）
   - 4枚の候補を表示
   - 選択した画像をキャンバスに挿入

### 受け入れ条件

- [ ] NanoBanana Pro APIが正しく接続されている
- [ ] プロンプト入力後「生成」ボタンで画像が生成される
- [ ] 生成中はスピナーが表示される
- [ ] 4枚の候補から選択できる
- [ ] 選択した画像がキャンバスに反映される
- [ ] エラー時は適切なメッセージを表示

## REQ-003: 動画コンポーネント - 外部URL対応

### 要件

**When** ユーザーが動画コンポーネントを追加する
**Then** 以下の動画ソースに対応する:

1. **YouTube**
   - 標準URL: `https://www.youtube.com/watch?v=xxxxx`
   - 短縮URL: `https://youtu.be/xxxxx`
   - 埋め込みURL: `https://www.youtube.com/embed/xxxxx`

2. **Vimeo**
   - 標準URL: `https://vimeo.com/xxxxx`
   - プレイヤーURL: `https://player.vimeo.com/video/xxxxx`

3. **その他の外部URL**
   - MP4ファイル直リンク
   - HLS/DASHストリーミングURL

### 設定項目（UTAGE準拠）

| 項目 | オプション |
|------|-----------|
| 動画タイプ | YouTube / Vimeo / 外部URL |
| 自動再生 | しない / ミュート再生 / 音声付き再生 |
| コントロールバー | 表示 / 非表示 |
| 再生時間表示 | ON / OFF |
| 再生速度変更 | 有効 / 無効 |
| ループ再生 | 有効 / 無効 |
| 最大化ボタン | 有効 / 無効 |
| 再生ボタン色 | カラーピッカー |

### 受け入れ条件

- [ ] YouTube URLを貼り付けると動画プレイヤーが表示される
- [ ] Vimeo URLを貼り付けると動画プレイヤーが表示される
- [ ] MP4 URLを貼り付けると動画プレイヤーが表示される
- [ ] 自動再生設定が正しく動作する
- [ ] コントロールバーの表示/非表示が切り替わる
- [ ] 不正なURLの場合はエラーメッセージを表示

## REQ-005: AIウィザードモード - LP自動生成

### 要件

**When** ユーザーがAIウィザードモードを選択する
**Then** 5ステップの質問に回答するだけでLPを自動生成する

### 質問フロー

1. **ステップ1: 商品名**
   - 商品・サービス名の入力
   - 例: オンライン英会話講座

2. **ステップ2: ターゲット**
   - ターゲット顧客の属性
   - 例: 30代のビジネスパーソン

3. **ステップ3: 悩み・問題**
   - 顧客が抱える悩み3つ
   - 例: 英語が話せない、時間がない、続かない

4. **ステップ4: ベネフィット**
   - 商品で得られる価値3つ
   - 例: 3ヶ月で日常会話、1日15分、サポート付き

5. **ステップ5: CTA**
   - 行動喚起の内容
   - 例: 今すぐ無料体験に申し込む

### 生成内容

- ヘッドライン（太陽スタイル準拠）
- サブヘッド
- 問題提起セクション
- 解決策セクション
- ベネフィットリスト
- 社会的証明（テンプレート）
- CTA ボタン
- 追伸（P.S.）

### 受け入れ条件

- [ ] 5ステップの質問が順番に表示される
- [ ] 各ステップで入力例が表示される
- [ ] プログレスバーで進捗が分かる
- [ ] 「戻る」ボタンで前のステップに戻れる
- [ ] 最終ステップでLP生成が開始される
- [ ] 生成中はスピナー + プレビューの更新が表示される
- [ ] 生成完了後、アドバンスドモードで編集できる

## 非機能要件

### NFR-001: パフォーマンス

- ページ読み込み: 3秒以内
- コンポーネント追加: 100ms以内
- プロパティ変更: 即時反映
- AI画像生成: 5秒以内

### NFR-002: レスポンシブ

- デスクトップ: 1200px以上
- タブレット: 768px - 1199px
- モバイル: 767px以下
- プレビュー切り替え対応

### NFR-003: アクセシビリティ

- キーボード操作対応
- スクリーンリーダー対応
- コントラスト比4.5:1以上

### NFR-004: セキュリティ

- 画像アップロード: ファイル検証
- XSS対策: サニタイズ処理
- CSRF対策: トークン検証
